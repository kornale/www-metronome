Promo-Code einlösen

Danke, dass du Polypulser testest! Den Promo-Code löst du im App Store oder bei Google Play ein. Wähle dein Handy und folge den Schritten.

Die Screenshots sind auf Englisch. Auf deinem Handy stehen die Menüs an derselben Stelle, nur auf Deutsch.

iPhone & iPad

  1. Öffne den App Store und tippe oben rechts auf dein Profilbild.

    Du siehst es nicht? Tippe zuerst unten auf Heute.

  2. Tippe auf Code einlösen.

    Auf älteren iOS-Versionen heißt die Zeile Geschenkkarte oder Code einlösen.

  3. Falls die Kamera aufgeht, wähle die manuelle Eingabe. Gib deinen Code ein und tippe auf Einlösen.

    XXXX XXXXEinlösen

Android

  1. Öffne Google Play und tippe oben rechts auf dein Profilsymbol.

  2. Tippe auf Zahlungen und Abos.

  3. Tippe auf Code einlösen.

  4. Gib deinen Code ein und tippe auf Einlösen.

    XXXX XXXXEinlösen

Fertig. Der Store bestätigt den Code, danach kannst du Polypulser öffnen.

Klappt es nicht?

Prüfe den Code zuerst auf Tippfehler. Wenn es dann immer noch nicht geht, schick einen Screenshot der Meldung und dein Handymodell an:

support-polypulser@forpilot.ch
